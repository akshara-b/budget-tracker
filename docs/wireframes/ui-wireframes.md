## 🎨 Design System

### Color Palette
```
Primary Colors:
- Primary Blue: #3B82F6
- Primary Green: #10B981
- Primary Red: #EF4444
- Primary Yellow: #F59E0B

Neutral Colors:
- White: #FFFFFF
- Light Gray: #F3F4F6
- Gray: #9CA3AF
- Dark Gray: #374151
- Black: #111827

Status Colors:
- Success: #10B981
- Warning: #F59E0B
- Error: #EF4444
- Info: #3B82F6
```

### Typography
```
Headings:
- H1: 32px, Bold
- H2: 24px, SemiBold
- H3: 20px, SemiBold
- H4: 18px, Medium

Body Text:
- Large: 16px, Regular
- Medium: 14px, Regular
- Small: 12px, Regular

Font Family: Inter, system-ui, sans-serif
```

### Component Spacing
```
Spacing Scale:
- XS: 4px
- S: 8px
- M: 16px
- L: 24px
- XL: 32px
- XXL: 48px

Component Padding:
- Cards: 24px
- Forms: 32px
- Buttons: 12px 24px
- Inputs: 12px 16px
```

### Interactive Elements
```
Buttons:
- Primary: Blue background, white text
- Secondary: Gray background, dark text
- Danger: Red background, white text
- Ghost: Transparent background, colored text

Inputs:
- Border: 1px solid #D1D5DB
- Focus: 2px solid #3B82F6
- Error: 2px solid #EF4444
- Success: 2px solid #10B981

Hover States:
- Buttons: 10% darker
- Cards: Subtle shadow increase
- Links: Underline or color change
```
